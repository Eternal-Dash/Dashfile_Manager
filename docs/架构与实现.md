## 0. 三十秒速览

- **是什么**：Windows 桌面端安卓设备管理工具（ADB + root），替代手机上的 MT 管理器；手机端**不装任何 App**。
- **在哪**：仓库根目录即源码；发布的便携目录为 `DashFile\`（整包可拷，不写注册表、不装服务）。
- **怎么跑**：双击 `DashFile\DashFile.exe`；发版见 §1。
- **作者**：恒定破折号（EternalDash），酷安 @恒定破折号（设置页与各页右下角有署名）。
- **体量**：`src/` 79 个 C# 文件约 15.8k 行 + 13 个 XAML 约 2.5k 行；EXE 约 27 MB（单文件 + 压缩 + 裁剪）；冷启动 **0.6 s**。
- **当前版本号**：`1.0.0`（`AppInfo.Version` 是唯一来源，改版本时同步 README 与变更记录）。
- **能力概览**：多 Root 管理器适配（KSU 系 / Magisk 系 / APatch / SuperSU / phh / Lineage）+ 插件系统（`DashFile.PluginApi`）。

### 发版

```powershell
cd <仓库根目录>
powershell -ExecutionPolicy Bypass -File build\publish.ps1
```

脚本：杀进程 → 清输出 → `dotnet publish`（自包含单文件 + 压缩 + **裁剪 partial**）→ 补 `Binaries\`、`Log\`
→ 同步 `使用说明.txt` / 插件开发指南 → 调用 `build\build-plugins.ps1` 构建插件到 `build\plugin-dist`（**不进发布包**）。
实测：EXE 约 27 MB / 整包约 37.5 MB / 冷启动 0.6~0.9 s（裁剪项见 `DashFile.csproj` 的 `TrimmerRootAssembly`）。
裁剪注意：自己的程序集、Avalonia、Skia、CoreLib、压缩、证书都要 root；
否则会分别报 `No precompiled XAML found` 或插件 `Attempted to access a missing method`。

只重建插件（不重新发布主程序）：

```powershell
powershell -ExecutionPolicy Bypass -File build\build-plugins.ps1 -OutputDir build\plugin-dist
```

## 3. 架构与数据流

```
View ──绑定/事件──> MainViewModel ──> Services ──> adb.exe / 设备文件系统
        ↑                    │
        │                    ├─ RootProviders ──> IRootProvider（KSU / Magisk / APatch / …）
        │                    └─ PluginManager ──> 外部插件 dll（AssemblyLoadContext）
        └── 资源字典（ThemeService 写入）┘
```

### 3.1 设备连接

```
DispatcherTimer 1.2s  +  WM_DEVICECHANGE(60ms 防抖)
   → adb devices -l → 签名变化才处理
   → ApplyDeviceList → ConnectAsync
        └─ _apps=null; _modules=null; _su=null; 清 _dirCache/_listCache（换设备必须重建）
```

### 3.2 文件浏览

```
NavigateAsync(path)
 ├ _listCache 命中(2.5s) → 直接用
 ├ 否则 adb ls -l -Z -- 'path/'
 ├ ApplySort（排序+筛选）
 └ 后台 SyncTreeAsync（结构变才重建树；否则只改高亮）
```

### 3.3 应用列表（三种模式）

```
AppMode 0 = 用户应用(pm -3)   1 = 系统应用(pm -s)   2 = 超级用户(用户应用 + shell)
每项并发补：版本(dumpsys) / 名称(arsc) / 图标(解析管线)
```

### 3.4 Root 识别与能力

```
ConnectAsync
 └─ IsRoot? → RootProviders.DetectAsync(_fs)
       ├─ 一次 root shell 收集证据（su -v / .allowlist 指纹 / ksud / magisk.db / apd / /proc/modules / 包名）
       ├─ RootProviderRegistry.Factories（按注册顺序）
       │    KSU → APatch → Magisk 系 → SuperSU → phh → Lineage → Unknown
       ├─ 每个 factory 只判断自己的家族，返回 IRootProvider 或 null
       ├─ 管理器包名只用于显示名 + 版本 + ManagerInstalled
       └─ 返回 IRootProvider（CanReadGrants / CanManageGrants / GrantHint / 模块命令 / 软重启）
```

新增一种 Root 实现：实现 `IRootProvider` + `IRootProviderFactory`，在
`RootProviderRegistry.Register` 插入即可；不需要改 `DetectAsync` 的 if/else。

- KSU 系：读 `/data/adb/ksu/.allowlist`（兼容 `allowlist` 文件名）；写前备份、写后回读。
- Magisk 系：`magisk --sqlite` 读写 `policies` 表；写前备份 `magisk.db`，改完回读；立即生效。
- APatch / SuperSU / phh / Lineage：识别 + 模块能力，授权表只读（格式未公开/不稳定）。
- `ModuleService` 用 provider 的 `ModuleInstallCommand` / `ModuleUninstallCommand`；失败自动退回
  `/data/adb/modules_update` + `.update` 或 `remove` 标记。

### 3.5 插件系统

```
启动 → InitializePluginsAsync
 └─ PluginManager.LoadAllAsync
      ├─ 扫描 plugins\<id>\plugin.json（exe 旁 + %LOCALAPPDATA%\DashFile\plugins）
      ├─ 每个插件一个可回收 AssemblyLoadContext
      │    ├─ DashFile.PluginApi / Avalonia / System.* → 复用宿主程序集
      │    └─ 其它依赖 → 从插件目录加载
      ├─ 实例化 IDashFilePlugin → InitializeAsync(IPluginHost)
      └─ 插件注册：AddPage / AddAction / AddGlobalAction
UI：插件页左侧列表 + 右侧页面；文件/应用/模块右键菜单追加插件动作
```

- 插件 API 契约在 `src/DashFile.PluginApi`，发布时复制一份到 `sdk\DashFile.PluginApi.dll` 供插件编译。
- 单个插件初始化失败只标记该插件 Error，不影响其它插件，也不影响主程序。
- 禁用 / 重载会调用 `ShutdownAsync`、清注册表、恢复插件做的 UI 资源覆盖、`AssemblyLoadContext.Unload()`。
- UI 扩展：`IPluginUi.OverrideResource/OverrideResourceColor/ClearResourceOverrides`，可改主题色、圆角、行高等动态资源；
  覆盖句柄由宿主记录，插件卸载时自动恢复。
- 当前只保留 1 个「逆向工具箱」示例插件（`samples\ReverseToolboxPlugin`），发布包默认不预装；`build-plugins.ps1` 构建到 `build\plugin-dist`。

### 3.6 主题与风格

```
ThemeService.ApplyStyle(styleKey, accentHex)
  ├ m3     → 主题色轻染表面（12px 圆角）
  └ miui   → 更亮的面（20px 圆角）
（glass / mono 已从 UI 移除，老配置会自动归位到 m3）
同时写 SystemAccentColor*，避免 Fluent 残留系统蓝
```

### 5.4 动画

| 元素 | 参数 |
|---|---|
| 页面切换 | 淡入 + 上移 10px，210ms CubicEaseOut（每次切页都播） |
| **标签滑动指示器** | translateX + Width，260ms QuarticEaseOut |
| **应用页分段指示器** | 同上，260ms |
| **切目录滑入** | translateX ±24px + 透明度 0.4→1，180ms；首屏只淡入 |
| **列表/树滚动** | 平滑滚动：滚轮 → 150ms CubicEaseOut，步进≈视口 10% |
| **目录树展开箭头** | rotate 90°，160ms；行悬停/当前色 120~160ms |
| **行/按钮悬停** | 白色叠层 alpha 0→7%（110ms）；按下 0→12.5%。**只用叠层，不做颜色插值** |
| **选中行悬停** | 不叠加（选中态必须始终是最亮的一格；列表选中用 Opacity 叠层盖在悬停层上面） |
| **选中行** | 行自身填 SelBg（随行滚动/虚拟化，不再用浮动滑块） |
| **树当前项** | 浮动高亮滑动 180ms QuarticEaseOut（Canvas 在滚动内容里，天然跟随） |
| **对话框** | 内容淡入 + 上移 8px，180ms（`ViewAnimator.AttachWindow`） |
| **按钮/卡片** | 按下 scale 0.97（90ms）；模块卡片悬停上浮 1px（160ms） |
| Toast | 上移 12px / 170ms |
| 开关 | 轨道 160ms + 滑块 Thickness + 按下 scale 0.94 |

> **为什么悬停用半透明白、而不是不透明深色？**
> Avalonia 11 的 `BrushTransition` 在非预乘空间插值：`Transparent(#00FFFFFF)` → `#FF2A2537`
> 的中途会经过 `#706E73`（实测亮度 110），比选中态 `SelBg`（亮度 54）亮一倍，
> 鼠标划过就是“闪一下白光”。改成同色白叠层后，中途任何一帧都 ≤ 终点亮度。

## 6. 关键实现

### 6.1 ADB
- 普通命令 20s 超时，取流 10min
- `ArgumentList` 直传，不拼字符串；需 shell 语义时显式 `sh -c` + `Sh.Q()`
- **`adb push` 是以 shell(uid 2000) 跑的**，写 `/data/adb` 必须先推 `/data/local/tmp` 再 `su cp`

### 6.2 只读原则
浏览类操作不在设备留文件；临时物只在本机 `%LOCALAPPDATA%\DashFile\`；退出时清设备端 `dashfile_*`。

### 6.3 退出清理
`Closing` → 取消 → 遮罩「正在清理临时文件」→ 清理（设备临时物 + 本机 `%TEMP%\dashfile*`、`DashFileDrag`、`dashfile_w_*` + 图标缓存 >60MB 清空）→ 最短 700ms → 关闭。

### 6.4 压缩包
双击 zip → 解到 `/data/local/tmp/dashfile_zip_<rand>` → 编辑 → `tar -czf` → 下载 → **本地转标准 zip** → 上传覆盖 → 清理。

### 6.5 图标管线
```
缓存 icons/<pkg>.png + .exact 标记
① 精确：manifest@icon → arsc → drawable
    vector / adaptive-icon / layer-list / inset / bitmap / color
    vector → VectorDrawableRenderer(96px)；adaptive → 前景+底色+72/108 圆形遮罩
② 兜底：unzip -l 按名字打分（排除 background/notification）
③ 仍失败：字母色块
校验：PNG 魔数、≥24px、非全透明；缓存版本 .v9（升级时连 *.png/*.exact 一起清）
资源路径兼容：res/ 与资源混淆后的 r/（ColorOS 等）
```

### 6.6 应用名称
`application@label` → arsc 字符串，优先级 **zh-CN > zh(其它) > 默认语言**；写 `labels.json`。
`com.android.shell` 名称硬编码为「Shell（adb 调试）」，**不走解析**（会取到错误字符串）。

### 6.7 KernelSU 授权表（SuperuserService）
```
/data/adb/ksu/.allowlist（兼容 /data/adb/ksu/allowlist）
  "USK" 魔数 + 文件头 + N 条定长记录。实测两种布局，读时逐个候选校验（包名可读 + uid 合理）后采用：
    老版：头 12 字节，记录 780 字节，包名在记录 +0
    新版（KernelSU-Next / SukiSU 3.x）：头 8 字节，记录 784 字节，包名在记录 +4
          （包名前多出的 4 字节含义未知，全表都是 4；新增记录时照抄同表记录）
  记录内（相对包名）：包名256 | uid(+256) | allow(+260) | 固定1(+268) | 上下文(+700) | flags(+772)
  2026-10-23 修正：以前写死 780，(长度-头) 不是 780 的整数倍就整表判"格式不支持"，
  新版 784 的表因此显示"—"（实测 KernelSU 3.2.5：7848 字节 / 10 条）。
写：push 到 /data/local/tmp → su "cp -f 到目标"（**不能 mv/unlink，SELinux 拒绝**）→ 回读校验长度
备份：存到电脑 %LOCALAPPDATA%\DashFile\su\（设备零残留）
新增记录：克隆同表记录的前缀 + 按相对偏移填字段；删记录后按原字节重建（不改其它条目）
生效：需软重启（ksud soft-reboot；没有该命令时退回 setprop ctl.restart zygote）
验证：切换单条只改 1 字节（allow 位于 1056），切回后原文件 MD5 一致；新增/删除后也字节级还原
```

### 6.8 Magisk 授权表（MagiskProvider）
```
/data/adb/magisk.db  policies(uid INTEGER, policy INTEGER, until, logging)
读：pm list packages -U → uid↔包名；magisk --sqlite "SELECT uid,policy FROM policies"
写：先备份 magisk.db 到电脑 → 有行 UPDATE / 无行 INSERT OR REPLACE → 回读校验
语义：policy=1 允许，0 拒绝（2=询问按未允许显示）
生效：MagiskSU 每次查库，改完立即生效，不需要重启
```

### 6.9 插件加载（PluginManager）
```
plugins\<id>\plugin.json → PluginManifest
入口 dll 必须位于插件目录内（防路径穿越）
AssemblyLoadContext（collectible）
  ├─ DashFile.PluginApi → 返回宿主程序集（类型身份一致）
  ├─ Avalonia.* / System.* / CommunityToolkit.* → 交默认上下文
  └─ 其它依赖 → 插件目录
InitializeAsync(IPluginHost) → AddPage / AddAction / AddGlobalAction

```

### 6.13 性能与空间（2026-10-23 优化）
```
应用版本：list>=20 时一次 `dumpsys package | grep -E 'Package \|versionName='`
          （以前每个应用一次 dumpsys，370 个 ≈ 30 秒；现在 1 次，约 856 行；
           实测 399 个 versionName 在 661ms 内完成，OPD2413 / Android 16）
标签缓存：ConcurrentDictionary + 每 20 个新名称写一次 labels.json + 退出 FlushLabels
          （以前每个新标签全量重写文件）
解包探测：SemaphoreSlim 单飞，370 个并发任务只探测一次 unzip/busybox
图标缓存：EnsureCacheVersion 进程内只 stat 一次 marker
Root 证据：一次 shell + 字典解析（不再对每个字段跑 Regex）
临时文件：统一 DevicePaths.TempFile / TempDirectory；退出清理 .dashfile*/dashfile_*
目录常量：AppPaths / DevicePaths / AppInfo / AppEnvironment 收口
目录树：TreeRow 原地改值 + BulkObservableCollection.Patch 增量增删
        （普通导航 patch 0~1ms；以前每次结构变化 ReplaceAll=整树 Reset，
          200 行约 30~40ms，且树越大越卡，后台补箭头时还会再卡一次）
树列目录：`ls -1p` 只取子目录 + 45s 树缓存；祖先链并发加载 + 同节点 in-flight 去重
树补箭头：只补当前展开节点；shell glob `"$d"/*/` 判断有无下一级（见踩坑 9）
滚动：SmoothScroll 行为（滚轮 → 150ms 缓出），文件/树/模块/应用/插件列表
```

## 7. 踩坑清单（改动前必读）

1. `ScrollViewer` 会让内部 `*` 行失效。
2. `Background=null` 不参与命中测试 → 要 hover/点击必须 `Transparent`。
3. `/sys/module/kernelsu` 分不出 LKM；判据是 **`/proc/modules`**。
4. `ListBoxItem` 吞 PointerPressed → 自定义点击用 Tunnel。
5. `RunCommandAsync` 返回值末尾有 `[退出码] n` → 解析用正则。
6. KernelSU 安装会先删同名模块目录 → 必须本地校验 zip。
7. 设备没有 `zip`，只有 unzip。
8. `su` 会挂在授权弹窗 → 所有命令必须超时。
9. **`find -type d` 在 `/sdcard`(FUSE) 上静默返回空** → 用 `ls -1p` 看尾斜杠。
10. `pm list packages` 不带 `-f` 没 APK 路径。
11. 换设备/重连必须重建 `_apps`/`_modules`/`_su`。
12. Avalonia 的 `Win32Properties` 不可用 → 子类化窗口过程。
13. PowerShell 5.1 读 UTF-8 会乱码 → 判断编码用 Python。
14. `.ps1` 必须 UTF-8 BOM。
15. **XAML 改完先 `xml.dom.minidom.parseString` 校验**。
16. Toast/浮层不能放根 `DockPanel` 最后（会把页面挤窄）。
17. **同优先级样式后定义的胜出** —— `Button.seg.on` 会盖掉先写的 `Button.tabbtn.on`；
    要用 `Button.seg.tabbtn.on` 提高优先级，并放在后面。
18. **滑动指示器要和按钮状态解耦**：按钮的 hover/pressed 底色会盖住指示器 → 全部设 Transparent。
19. **`LayoutUpdated` 里刷新视觉树会形成抖动** → 只用 SizeChanged/属性变化触发，并加节流。
20. **`/data/adb/ksu` 目录 SELinux 禁止 mv/unlink**，只能 `cp -f` 原地覆盖。
21. **`pstore`（`/sys/fs/pstore/console-ramoops-0`）目录 `dr-xr-x---`**，删不掉 → "跨重启无痕"做不到。
22. `usagestats` / `recent_tasks` 受 SELinux 保护，硬删要 `setenforce 0` → **不要做**，那是最大的新痕迹。
23. 多次失败重试会在 `/data/adb/ksu/` 堆 `.bak` 文件 → 备份改存电脑。
24. `adb push` 不能直接写 `/data/adb`（见 6.1）。
25. **插件与宿主必须共用同一份 `DashFile.PluginApi` / Avalonia**：插件 ALC 对这两个名字必须返回宿主程序集，否则 `IPluginHost`/`Control` 类型身份分裂，表现为“插件实现了接口但宿主认不出”。
26. **`DashFile.PluginApi` 工程在 `src` 下**：主工程默认 `**/*.cs` 会把它和它的 `obj` 一起编译，导致 AssemblyInfo 重复。csproj 已用 `Compile Remove="DashFile.PluginApi\**\*.cs"` 排除；移动目录时记得同步。
27. **插件页控件必须在 UI 线程创建**：`CreateViewAsync` 由宿主在 UI 线程调用；插件自己在后台回调里创建控件会抛 “Call from invalid thread”。
28. **KSU fork 不只 KernelSU 一个包名**：不要用 `me.weishu.kernelsu` 判断家族；用 su -v / ksud / `.allowlist` 指纹，包名只取显示名。
29. **Magisk 写 `magisk.db` 必须回读校验**：`magisk --sqlite` 可能返回 0 但 SQL 报错；写入前备份到电脑，回读不一致要报失败，不能假装成功。
30. **APatch 的授权表不要瞎写**：`/data/adb/ap` 的格式不稳定，当前只识别 + 模块能力；授权交给 APatch App。
31. **插件页 ListBox 必须自定义 ItemContainerTheme**：默认选中底色是系统浅色，会把 `TextMuted` 压得几乎看不见。
32. **截图/DPI**：开发机 200% 缩放时窗口物理尺寸会超出屏幕，截图要用 `PrintWindow` 或按 DIP 尺寸截，不要用 `CopyFromScreen` 直接截窗口。
33. **目录树的小改动不要 `ReplaceAll`**：一次 Reset 会重建全部行容器，树越大越卡；用 `BulkObservableCollection.Patch(desired)` 做引用级增量，`TreeRow` 属性必须可观察、行对象复用。
34. **悬停/按下不要用“透明 → 不透明深色”的 `BrushTransition`**：Avalonia 11 在非预乘空间插值，中途会闪出比选中态还亮的灰（实测 110 vs 54）。一律用 `HoverLayer` / `PressedLayer` 这种“同色白、只变 alpha”的叠层；列表的选中/悬停用 `Opacity` 叠层（`selLayer` 压在 `hoverLayer` 上）。
35. **选中行/树当前项不能再叠悬停亮度**：`Border.row.sel:pointerover`、`Border.treeitem.current:pointerover` 必须显式设回 `SelGhost`，且“多选/兜底填色”的规则要放在它们**后面**，否则会把选中色压掉。选中底色的“透明”一律用 `SelGhost`（SelBg 的 alpha=0 版本，ThemeService 运行时生成），不要用 `Transparent`，否则选中/取消选中也会闪白。
37. **ListBoxItem / 树行的 Background 不要做补间**：拖拽落点（`CardSel`）是不透明色，从透明或悬停白叠层插值都会闪；FilesList 的拖拽高亮直接改 `ListBoxItem.Background`，树行 `:pointerover` 即时切换。
36. **PowerShell 5.1 的 `Get-Content -Raw` / `Set-Content` 会按 GBK 解码 UTF-8 源码**，中文和换行都可能被吃掉（本项目踩过：10 个对话框源码被毁）。改源码一律 `[IO.File]::ReadAllText/WriteAllText(..., UTF8)`；`.ps1` 用 UTF-8 BOM。

| 项 | 说明 |
|---|---|

| 深色壁纸下压暗层几乎看不出 | 同第 1 条 |

| 插件页面在窄窗口会被压窄 | 插件页左栏固定 300 DIP；窗口 <1100 DIP 时右侧内容会挤 |
| 插件 ALC 卸载不保证 100% 回收 | 插件若把静态事件挂到宿主上，可能阻止卸载；禁用后功能已移除，内存回收是次要问题 |
