# 开发规范（必须遵守）

> 这份文件是**约束**，不是建议。任何改动前先读一遍；违反其中条款 = 引入已知 bug。
> 配套文档：[架构与实现.md](架构与实现.md)（现状与细节）、[变更记录.md](变更记录.md)、`使用说明.txt`（用户向）。

---

## 一、改动流程（固定 6 步，不可跳）

```
1. 读现状        先看《架构与实现》对应章节 + 目标文件，不要凭记忆改
2. 说清改什么     一句话：改哪个文件、为什么、影响哪些页面
3. 改             小步修改；XAML 禁止"整段字符串替换"式大改
4. 校验          XAML 改完立刻 xml.dom.minidom.parseString(全文)
5. 编译           dotnet build -c Release -v q  →  0 error
6. 实跑+截图      起 exe → 定位到改动处截图 → 确认无裁切/重叠/错位
```

**只在"编译通过"就交付 = 不算完成。** 历史上多次因跳过第 6 步而返工。

## 二、XAML 铁律

| 禁止 | 原因 |
|---|---|
| 用字符串替换改大段 XAML | 锚点错位会静默破坏结构（曾导致整块 UI 消失） |
| 写死颜色值（`#RRGGBB`） | 主题切换失效；必须用 `{DynamicResource 键}` |
| 写死圆角/行高 | 风格切换失效；用 `RadiusCard/RadiusCtl/RadiusPill/RowH/TreeRowH` |
| 把页面塞进 `ScrollViewer` 求"填满" | 内部 `*` 行失效，底部留白 |
| 需要 hover/点击却设 `Background=null` | 不参与命中测试，"点不中" |
| 把浮层（Toast 等）放在根 `DockPanel` 最后 | 会把页面容器挤成内容宽度 |
| 在子窗口引用主窗口 `Window.Resources` 里的资源 | 运行时 `StaticResource` 解析失败；公共图形放 `App.axaml` |

**新增颜色**：先在 `App.axaml` 加资源键 → 再在 `ThemeService` 里为各主题赋值 → 最后在 XAML 引用。

## 三、布局规则

1. **页面不滚动**（设备页/应用页/设置页），靠 `Grid` 行分配填满；文件页列表允许滚动。
2. **对齐优先用同一 `Grid` 的行**，不要用两套独立布局靠 `Margin` 对齐。
3. 固定列宽优先：右栏、留白区用像素；只有内容列用 `*`。
4. 拖放区（虚线框）必须 `IsHitTestVisible="False"`，事件穿透到列表。
5. 小尺寸元素（图标、箭头）≥12 DIP；正文 ≥12.5 DIP；参数值 ≥13 DIP。

---

## 四、代码分层

| 层 | 允许 | 禁止 |
|---|---|---|
| `Views/*.axaml` | 布局、绑定、样式类 | 业务逻辑、adb 调用 |
| `Views/*.axaml.cs` | 事件转发、UI 交互（拖拽/对话框） | 复杂业务、直接跑 adb |
| `ViewModels/*` | 状态 + 业务流程 + 缓存 | 直接 `new Window()`（用对话框静态方法） |
| `Services/*` | 纯功能（adb、解析、渲染、插件加载） | 引用 `MainWindow`、依赖 UI 线程 |
| `DashFile.PluginApi/*` | 稳定的外部契约（接口、DTO、基类） | 引用 DashFile 主程序、静态状态 |
| `ViewModels/PluginHostBridge.cs` | 把插件 API 调用转成 VM/Services | 让插件直接摸 VM 私有状态 |

**新增功能放哪**：
- 需要 adb 的 → `Services/`
- 需要界面的 → `Views/` + 在 VM 加方法
- 纯数据 → `Models/`

---

## 五、线程规则

1. UI 状态只能在 **UI 线程**改：跨线程用 `Dispatcher.UIThread.Post/InvokeAsync`。
2. `ObservableProperty` 赋值同样受此约束。
3. 后台任务必须 `try/catch`，异常不得逃逸（`App.axaml.cs` 有兜底日志，但不要依赖它）。
4. 长循环要检查 `CancellationToken`；当前只有列表加载有 CTS，新增长任务必须自带。

---

## 六、ADB 规则

1. **一切命令有超时**（`AdbRunner.Timeout` 20s / `ExecTimeout` 10min）。
2. **参数分开传**（`ArgumentList`），不要拼字符串；必须 shell 语义时显式 `sh -c` + `Sh.Q()`。
3. **只读优先**：浏览类操作不允许在设备建文件。
4. **写操作必须由用户明确触发**（卸载、保存到手机、刷模块）。
5. **换设备/重连后**：重建 `_apps`、`_modules`，清 `_dirCache`、`_listCache`。
6. **命令返回值带 `[退出码]`**：解析数字用正则 `(?m)^\s*(\d+)\s*$`。
7. 不要用 `Find -type d` 列 `/sdcard` 子目录（FUSE 下为空），用 `ls -1p`。

## 七、性能红线

| 场景 | 要求 |
|---|---|
| 切目录 | 列表 ≤100ms 出现（`ls` 一次；2.5s 缓存避免重复） |
| 树点击 | 不重建整棵树；只更新 `IsCurrent`（`PreviewTreeCurrent` 先给反馈） |
| 树结构变化 | 用 `BulkObservableCollection.Patch` 增量；**禁止**对小改动 `ReplaceAll`（Reset 会重建全部行容器，树越大越卡） |
| 树列目录 | `ls -1p` 只取目录 + 45s 树缓存；祖先链并发加载；同节点 in-flight 去重 |
| 列目录选择器 | 单条命令（`ls -1p`），禁止逐条探测 |
| 应用列表 | 包名+路径一次拿全（`pm list packages -f`），其余后台补 |
| 图标渲染 | 96px，缓存到磁盘，版本号变更才重取 |
| 滚动 | 滚轮必须走 `SmoothScroll`（150ms 缓出），不要退回系统离散跳变 |

### 7.1 动效

- **时长**：微交互（按下/悬停）90~140ms；小过渡（箭头/高亮）160~180ms；页面/对话框 180~220ms；滑动指示器 ≤260ms。
- **缓动**：`CubicEaseOut` / `QuarticEaseOut`；不要 Linear（机械）或 Bounce。
- **属性**：优先只动 `RenderTransform` / `Opacity` / `Brush`；`Width` 只在滑动指示器这种低频元素上用。
- **统一入口**：页面用 `ViewAnimator.Attach`，对话框用 `ViewAnimator.AttachWindow`，滚动用 `SmoothScroll.Enabled="True"`，不要在页面里另写一套。
- **不抢操作**：动画只做"确认状态变了"，不阻塞输入；连续操作时新动画从当前值续上。
- **悬停/按下只用叠层**：`HoverLayer`（7% 白）/ `PressedLayer`（12.5% 白），禁止 `Transparent` → 不透明深色的 `BrushTransition`（非预乘插值会闪出比选中态亮一倍的灰）；列表的选中/悬停用 `Opacity` 叠层（`selLayer` 在 `hoverLayer` 上面）。
- **选中必须最亮**：选中行/树当前项不响应悬停（`:pointerover` 显式设回 `SelGhost`）；hover 的终点亮度必须低于 `SelBg`。
- **主文件区悬停用 `FileHover`**（12% 白），列表/树用 `RowHover`（7% 白）；两者都只变 alpha。
- **右键菜单必须带图标**：用 `MenuIcons.Item(header)` 创建，按文字自动匹配，不要裸 `new MenuItem`。
- **插件动作只挂「插件」子菜单**，单个插件直接列动作，多个插件按插件名分组；动作可自带 `Icon` 路径。
- **拖拽浮层不参与命中测试**：拖入落点条/提示浮层必须 `IsHitTestVisible=False`，否则会截走 DragOver，导致目标高亮冻结、界面闪烁；拖拽反馈只在目标变化时更新。
- **文件行悬停由代码驱动**：`PointerMoved` 只给当前行加 `.hover` 类，离开/滚动/开始拖动就清；不要只依赖 `:pointerover`（窗口失焦/程序化移动指针会残留）。
- **细白线**：卡片、右键菜单、选中滑块统一用 `Hairline`（#2BFFFFFF）1px 描边；总览/分区用 `HairlineSoft`。

### 7.2 稳定性（必须遵守）

- **禁止裸 `_ = XxxAsync()`**：一律 `XxxAsync().Safe("操作名", m => StatusText = m)`，让异常立即进日志而不是等 GC。
- **配置/缓存写入必须原子**：`AtomicFile.WriteAllText/WriteAllBytes`，不要直接 `File.WriteAllText`（半截 json 会清空设置）。
- **定时器必须有重入守卫**：进入置忙、`finally` 复位；断开连接要 `Stop()`，`StartMonitor` 必须可重复启动（不要 `if (_monitor != null) return` 后忘了 Start）。
- **插件调用必须有超时**：Initialize/Shutdown 5s；超时标 Error 并写 plugins.log，防止一个插件挂死整个插件页。
- **网络/端口探测要可取消**：用 `CancellationTokenSource(ms)` + `await ConnectAsync(..., token)`；禁止 `Task.WhenAny` 后弃置 Task。
- **单实例**：不要并发启动多份（会抢 adb server / 图标缓存 / settings.json）；调试时先杀进程再起。

## 八、发布规则

1. 只通过 `build\publish.ps1` 发版；参数不得修改。
2. 发布前必须杀 `DashFile.exe` 与本目录 `adb.exe`。
3. 发布后**从 exe 抽图标/启动一次**确认没坏。
4. 版本号变更时同步：`AppVersion`（VM）、`使用说明.txt`、本目录文档。
5. 产物体积：EXE ≤45 MB、整包 ≤56 MB、启动 ≤0.8 s。

## 十、命名与风格

- C#：`PascalCase` 类型/方法，`_camelCase` 字段，`Async` 后缀表示异步。
- XAML：`x:Name` 用 PascalCase；样式类用小写（`tool` `pri` `seg` `appact`）。
- 资源键：语义化（`PanelAlt`、`AccentBg`），不要用颜色名。
- 注释：写"为什么"，不写"是什么"；踩过坑的地方留一句"不这样做会怎样"的说明。

## 十二、本轮新增的硬规则（2026-10-22）

### 样式优先级
- Avalonia 里**同优先级选择器，后定义的胜出**。
- 给某个子类只改一件事时，用**更长的选择器**提权（`Button.seg.tabbtn.on`），不要靠"写在后面"碰运气。

### 动画
- 任何"滑动指示器"都必须与按钮状态解耦：按钮 `:pointerover` / `:pressed` / `.on` 的背景全部设 `Transparent`，否则会盖住指示器。
- 过渡只加在**位置/宽高/透明度/背景刷**上，不加在 `Margin`（不可过渡）。
- 刷新视觉树（找卡片、算坐标）**禁止挂在 `LayoutUpdated`**，会抖动；用 `SizeChanged` / 属性变化 + 150ms 节流。

### 设备端写文件
- `adb push` 是 shell 身份，**不能直接写 `/data/adb`**。流程固定为：
  `push → /data/local/tmp/<random>` → `su -c "cp -f 到目标; chmod; rm 临时"`。
- `/data/adb/ksu` 目录 **SELinux 禁止 mv/unlink**，只能原地覆盖；也不要创建中间文件。
- 备份类文件**一律存电脑**，不在设备留 `.bak`。

### 清理痕迹
- 只删文件，保留目录（`rm -f /dir/*`，不要 `rm -rf /dir`）。
- 受系统保护的路径（`pstore`、`usagestats`、`recent_tasks`）**不要尝试**，更不要 `setenforce 0`。
- 关 USB 调试/开发者选项必须是**最后一步**（`adb_enabled 0` 会立刻断连）。

### 交互与交付
- **不要主动打包、不要主动发送文件**，只有用户明确要求时才做。
- 每个功能改完必须实跑 + 截图确认，不能只"编译通过"。

### 常量与路径（2026-10-23）
- 设备端固定路径一律从 `DevicePaths` 取（`/data/adb`、`/data/local/tmp`、`/sdcard`…），不要在业务代码里写字符串。
- 本机固定目录一律从 `AppPaths` 取（`%LOCALAPPDATA%\DashFile\…`）。
- 设备临时文件用 `DevicePaths.TempFile/TempDirectory`，保证退出清理的 `.dashfile*` 前缀统一。
- 版本 / 署名 / 产品名 / shell 包名从 `AppInfo` 取；`DASHFILE_*` 调试参数从 `AppEnvironment` 取。
- 新增 Root 实现：实现 `IRootProvider` + `IRootProviderFactory`，注册到 `RootProviderRegistry`；
  不要往 `DetectAsync` 里加 if/else。

### 插件（2026-10-23）
- 外部插件只允许引用 `DashFile.PluginApi`；不要让它引用 `DashFile.exe` / `DashFile.dll`。
- 插件 ALC 对 `DashFile.PluginApi`、`Avalonia.*`、`System.*` 必须返回宿主程序集 / 默认上下文；
  否则会出现两套 `IPluginHost` / `Control` 类型。
- 插件加载失败必须隔离：单个插件报错不能影响主程序或其它插件。
- 插件 UI 创建只能在 UI 线程；后台回调用 `IPluginUi.RunOnUiThread`。
- 插件页 ListBox 必须自定义 `ItemContainerTheme`，不能依赖默认选中底色（浅色会压掉 `TextMuted`）。
- 新增插件 API 优先用“加新接口/新类型”的方式，不要改已有签名；破坏性改动必须递增
  `PluginApiInfo.Version` 并在插件页拒绝旧版本。
- 插件改 UI 统一走 `IPluginUi.OverrideResource`，不要直接操作 `Application.Current.Resources`；
  宿主负责记录原值，插件禁用/重载时恢复。
- 发版自带插件由 `build\build-plugins.ps1` 构建；`publish.ps1` 会调用它，不要手工复制 DLL。

### 性能与编码（2026-10-23 文件树提速）
- 目录树/长列表的小改动一律 `Patch` 增量；行对象按业务 key 缓存复用，属性可观察。
  禁止用 `ReplaceAll`（一次 Reset 会重建全部行容器，元素越多越卡）。
- 树列目录用 `ls -1p`（只要目录）；FUSE（`/sdcard`）上不要用 `find -type d`，会静默返回空。
- 补"有没有下一级"用 shell glob `"$d"/*/`，一条命令、不 fork。
- 修改含中文的源码：禁止 PowerShell 5.1 的 `Get-Content -Raw` / `Set-Content`（会按 GBK 解码 UTF-8，
  中文和换行都可能被吃掉）。用 `[IO.File]::ReadAllText/WriteAllText(..., UTF8)` 或 edit 工具。
- 动效参数集中在 `ViewAnimator`（页面/对话框）和 `SmoothScroll`（滚轮）；新增动画先复用它们。
