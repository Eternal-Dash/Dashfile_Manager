DashFile 内测说明
=================

【这是什么】
电脑端（Windows）的安卓设备管理工具。不用在手机上装任何东西，
插 USB 打开「USB 调试」就能用，有 root（KernelSU）时还能读写系统目录、管理模块。


【怎么开始】
1. 解压整个文件夹（不要只把 exe 拖出来，Binaries 里的 adb 是必需的）
2. 手机：设置 → 关于手机 → 连点版本号 7 次 → 开发者选项 → USB 调试
3. 插线 → 手机弹「允许 USB 调试」→ 点允许
4. 双击 DashFile.exe
5. 顶部出现「机型 · 序列号」和「已获取 ROOT」就成功了

没有 root 也能用：看文件、看应用、卸载应用、装 APK 都不需要 root。
只有读写系统目录 / 管理模块 / 提权相关才需要。


【这一版请重点帮我测这些】
① 文件管理
   · 左侧目录树点击是否跟手（有没有明显卡顿）
   · 面包屑点击、表头排序（名称/日期/类型/大小/权限）、筛选
   · 长按 450ms 多选，拖到文件夹上松手 = 移动
   · 拖到窗口外 = 弹出 Windows 原生复制进度框
   · 右键菜单：解压 zip、安装 APK、权限 777、SELinux 标签、属性

② 应用管理
   · 图标是否正确（有没有显示成字母色块）
   · 名称是否中文（该显示英文的显示英文才对）
   · 详情弹窗 13 项有没有空的
   · 卸载、提取安装包（存电脑 / 存手机）
   · 右上「安装应用」从电脑装 APK

③ 模块管理
   · 开关是否跟手、位置会不会跳
   · 提取模块 → 生成的 zip 能否重新刷入
   · 拖 zip 进窗口刷模块

④ 超级用户（有 root 才显示）
   · 自己是什么 root 实现，设备页「Root 实现方式」是否显示正确
   · 开关能否写入、重启后是否生效
   · KernelSU 系改完需要软重启；Magisk 系应直接生效（不需要重启）

⑤ 多 Root 适配（重点）
   · KernelSU / KernelSU-Next / SukiSU Ultra / ReSukiSU / KowSU / MKSU
   · Magisk / Magisk Alpha / Kitsune Mask
   · APatch / SuperSU / phh's Superuser / LineageOS 内置 su
   · 能识别的请截图设备页 Root 卡片；不认识的请把 su -v 输出和 /data/adb 目录列表发我

⑥ 插件（随 Release 提供 2 个，均可热插拔）
   · 逆向工具箱：APK 分析页、应用/文件右键体检，Manifest / 签名 / DEX / 哈希是否正常
   · AVB 工作台：解析、签名、VMBeta 构建、整树重建、A/B 批处理、扫描；页签滑块与悬停是否跟手
   · 启用 / 禁用 / 重新加载是否需要重启（应该不需要）
   · 故意放一个坏 plugin.json，插件页是否显示错误、程序是否还能正常用
   · 卸载时勾「保留数据」与不勾的区别是否符合预期

⑦ 图标
   · ColorOS / 资源混淆 APK（例如浏览器）图标是否正常
   · 系统应用里框架/overlay 包显示字母块是正常的（它们没有 launcher 图标）

⑧ 设置
   · 黑白主题是否是默认
   · 7 个主题色切换是否即时生效
   · 标准 / MIUI 两套风格


【已知问题（不用报）】
· 极少数应用图标显示为字母色块（用了渐变矢量图，暂不支持）
· 系统应用首次加载较慢（370+ 个，要逐个解析图标）
· 上传/下载没有百分比进度，只有阶段文字
· 提取到手机时，目录选择器不显示隐藏文件夹
· 插件页面目前是嵌入「插件」页的，不是独立窗口
· 插件 API 还会继续加接口；破坏性改动会递增 apiVersion
