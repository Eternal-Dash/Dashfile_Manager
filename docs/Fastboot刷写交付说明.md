完成日期：2026-11-01。仓库 Eternal-Dash/Dashfile_Manager；本地基线 78aa123。本次是在既有浅色/玻璃材质验收修改之上新增插件，保留原有水平导航和其他页面布局。未向远程仓库提交、推送或发布 Release。

## 直接验收

桌面原有 **DashFile - 设计验收版** 快捷方式已经指向本次验收程序。打开后顶部“分区刷写”位于“设置”前；插件在该验收程序的便携插件目录中已启用。

本交付文件夹中：

- `com.dashfile.fastbootflash.dfp`：可独立安装的插件包。
- `DashFile-Fastboot-验收版.zip`：包含 API v2 宿主、该插件及 ADB/Fastboot 的便携验收包；完整解压后运行 DashFile.exe。
- `使用与开发说明.md`：功能、格式、构建方式、具体限制和 AOSP 参考链接。
- `验证结果.txt`：专项和宿主回归结果。
- `SHA256SUMS.txt`：交付文件校验值。

**旧版宿主无法单靠安装插件增加顶部入口。** 本次为宿主增加了 API v2 主导航和任务运行保护。请使用所附验收版，或从修改后的源码构建宿主；旧 API v1 插件继续兼容。插件要求 apiVersion=2，旧宿主将拒绝加载并提示升级。

## 本次改动

项目主要由 .NET 8 / Avalonia 桌面 UI、ViewModel、ADB/Root 设备服务和 .dfp 插件系统组成。插件通过独立 AssemblyLoadContext 加载，Avalonia、CommunityToolkit 与插件 API 由宿主共享。原有 AddPage 只显示在插件管理页，所以本次新增可选主导航扩展，并保持内置页编号不变。

新增插件提供：设备/分区识别、A/B 槽位解析、单镜像写入、AOSP Fastboot update ZIP / 镜像目录刷写、原生 fetch / ADB Root 回读、全部已枚举分区备份、ZIP 清单打包与同设备恢复、预览/双确认/进度/日志/停止后续任务。

界面采用已有主题色、浅深色资源、实线边界和轻量分段导航。镜像操作、固件包、批量回读、任务日志各有独立区域；任务运行时锁定输入，切页共享同一会话。没有为此改变应用原有布局，也没有加入额外背景模糊或高频动画。

宿主修改覆盖 API 契约/能力号、页面注册复制、主导航映射与刷新、动态标签按钮、长任务启停/卸载/重载/安装/正常关闭保护；构建脚本纳入新插件，插件开发指南和 schema 同步更新。另外修复同 ID 重复安装被拒绝时可能误删已有插件目录的回滚问题，并增加测试。

## 验收建议

1. 顶部“分区刷写”位于设置前。进入插件管理页禁用它，入口应消失；启用后恢复。检查其他旧插件仍正常显示。
2. 切换插件内部四个页签，查看路径、分区列表、计划区、日志、回读说明。插件管理页中的较小页面可整体滚动。
3. 使用自己的测试设备明确选择插件目标、读取分区，再生成计划；**只生成计划不会写入**。核对具体分区后再由你决定是否执行。
4. 真实刷写/回读/重启未替你执行。设备协议支持、厂商包兼容性、实际传输性能需要实机验收；镜像与机型是否匹配仍需人工核对。

## 已验证与边界

- 插件 Release 构建成功，0 警告、0 错误。
- 宿主自包含 win-x64 发布成功；宿主既有过时 API / 分析器警告仍存在，无编译错误。

- GUI 已核对导航插入、四页签、禁用移除/启用恢复及现有插件加载。
- 所有文件与哈希检查、镜像传输采用流式处理。没有实测 FPS，不能据此宣称已达到某个帧率。
- 原生 fetch 因设备而异，无法承诺所有手机在 Fastboot 中回读。全部回读仅覆盖已枚举分区，不是厂商全量救砖包。
- 备份恢复要求同机型、同序列号且清单完整；运行中的 Android 备份不能保证跨分区一致性。建议重要备份在合适的 Recovery / 未挂载状态执行。
- 整包支持范围与停止行为见“使用与开发说明”。不直接执行 OTA payload 或厂商脚本，不自动解锁、擦除、绕过 AVB 或系统重启。
