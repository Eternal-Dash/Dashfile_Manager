DashFile — 安卓设备文件管理器（电脑端）

【运行环境】
Windows 10 1809 及以上 / Windows 11（64 位）。
不需要安装 .NET 运行时，不需要单独装 adb，也不需要 VC++ 运行库 ——
程序是自包含单文件（约 27 MB），adb 已随包放在 Binaries\Adb\ 里。
若杀毒软件对单文件程序误报，把整个文件夹加入信任即可。

【怎么用】
1. 手机打开「开发者选项 → USB 调试」，用数据线连电脑。
2. 双击 DashFile.exe（不用装任何东西，免安装）。
3. 手机弹出「允许 USB 调试」时点允许；如果要用系统目录，再允许一次 root 请求。
4. 顶部下拉框出现机型 · 序列号、右侧显示「已获取 ROOT」就说明连上了。
   没有 root 也能用：浏览内部存储、看应用列表、卸载应用都不受影响。

【六个页面】
· 设备信息：22 项设备参数、Root 实现方式（KernelSU 系 / Magisk 系 / APatch / SuperSU / 原生 su）、
  超级用户/模块数量、CPU 与内存实时监控、快捷重启。
· 文件管理：左侧目录树（内部存储 / Root 实现目录 / 根目录三个快捷入口），右侧文件列表；
  双击进目录；文件双击会按后缀自动打开（文本/图片/APK/DEX/字体/音视频…），
  未知后缀会弹出「打开方式」菜单（18 种工具：文本、压缩包、图片、十六进制、Xml/Dex/Arsc/Class、
  Apk/Apks 信息、签名、字体、Svg、点九、脚本、音乐/视频）；
  可执行文件（.sh 或有 x 权限）双击不会直接运行，会打开「执行命令」页；
  该页右侧还有 音量−/音量+/电源 三个按键，方便给需要按键的脚本发事件；
  可上传/下载/改名/删除/改权限（777）/修 SELinux 标签；
  长按 450ms 进入多选；把文件拖到文件夹上是移动，拖到窗口外会弹系统的复制进度框。
· 模块管理：列出 /data/adb/modules，可启用/停用/卸载、提取成可安装的 zip；把 .zip 拖进来即可刷入。
· 应用管理：分「用户应用 / 系统应用 / 超级用户」，显示图标、名称、版本；
  每行右侧有「详情 / 卸载 / 提取安装包」三个按钮；
  右上「安装应用」可以直接把电脑上的 APK 装到手机。
· 插件：打开「插件」页，点「安装 .dfp」，或把 .dfp 文件直接拖进插件页。
  插件可以提供自定义页面，也可以在文件/应用/模块的右键菜单里加动作，甚至改主题色/圆角。
  发布包默认不带插件（保持干净）；桌面附带的「逆向工具箱」「AVB 工作台」都是 .dfp 插件包。
  卸载：选中插件后点「卸载」，可只删插件，也可一并删除它的设置/缓存。
  开关/重载后不需要重启程序。开发说明在 docs\插件开发指南.md。
· 设置：主题色（默认黑白，另有淡紫/冰蓝/薄荷/暖橙/樱粉/青柠）、界面风格（标准 / MIUI）。

【应用管理小提示】
· 图标是程序自己从安装包里解析出来的，个别应用可能解析不出来，会显示字母色块并标注「图标可能不准」。
· 卸载系统应用实际是「停用」，不会真的删除，需要时可在系统设置里恢复。
· 提取安装包可以选存到电脑（弹 Windows 保存框）或存到手机（程序内选目录）。

【快捷重启说明】
System / Fastboot / Fastbootd / Recovery / 9008(EDL)
9008 是高通紧急下载模式，进去之后手机屏幕会黑，需要专用工具才能退出，谨慎点。
如果手机已经在 9008 模式，程序识别得到但无法用软件重启，只能长按电源键 10~15 秒。

【连不上怎么办】
1. 换一根数据线或换 USB 口（优先主板后置口）。
2. 手机里「USB 调试」关掉再打开。
3. 点界面上的「重置连接」（会重启 adb 服务）。
4. 仍不行：拔掉数据线，等 3 秒再插，然后点「重新查找设备」。
   程序每 1.2 秒自动检测一次设备，插上后一般 3 秒内自动恢复。

【文件放哪】
· Binaries\Adb\      内置 adb（程序优先用这个，不依赖系统环境变量）
· Binaries\Fastboot\ 内置 fastboot
· plugins\           插件目录（一个插件一个子目录）
· sdk\               插件开发用的 DashFile.PluginApi.dll
· Log\                运行日志 / 崩溃记录（crash-日期.log、plugins.log）
· docs\插件开发指南.md 插件开发说明

【注意】
· 程序不写注册表、不装服务，整个文件夹可以直接拷到别的电脑用。
· 浏览操作严格只读，不会在手机上留下任何临时文件；退出时会自动清理。
· 修改系统分区文件有风险，操作前请确认自己知道在做什么。

【1.2.0 本地验收新增】
双轨快传插件启用后，设备文件上传/下载默认优先使用 USB + 可达 Wi-Fi。手机与电脑需在同一局域网；仅 USB 可达时真实显示单通道。插件页可检测通道、取消或关闭接管。原项目 HybridFileXfer / 原作者 weixiansen574，GPL-3.0-or-later，DashFile 适配说明见插件 UPSTREAM.md。
分区页提示“不支持 fetch”时需自行切至具备 Root 的 Android/Recovery 使用 ADB 回读。快传插件不能让不支持 fetch 的 Bootloader 获得分区回读能力。
拖动文件按 Escape 可取消；拖到桌面空白处或资源管理器文件夹导出，其他外部落点取消。
